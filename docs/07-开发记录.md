### 领域模型

  - `ClientApp` - 客户端应用（扩展了 clientId/clientSecret/signPublicKey/enabled 等字段）
  - `KeyMetadata` - 密钥元数据（algorithm/cryptoType/alias/keyVersion 等）
  - `KeyMaterial` - 密钥材料（publicKey/privateKey/secretKey）
  - `ClientKeyPermission` - 客户端密钥授权关系
  - `AuditLog` - 审计日志
  - `CryptoResult` - 加解密结果 DTO

### 公共模块

  - `AlgorithmEnum` - 加密算法枚举（RSA/SM2/AES/SM4/SIGN/MD5/SM3）
  - `CryptoTypeEnum` - 加密类型枚举
  - `KeyPurposeEnum` - 密钥用途枚举
  - `KeySourceEnum` - 密钥来源枚举
  - `OperationEnum` - 操作类型枚举（审计用）
  - `KmsException` - 业务异常
  - `IdUtil` - ID 生成工具

### 加密核心（pcm-kms-core）

  - `AlgorithmStrategy` - 算法策略接口
  - `AesAlgorithmStrategy` - AES-256-CBC 对称加密
  - `Sm4AlgorithmStrategy` - SM4 国密对称加密
  - `RsaAlgorithmStrategy` - RSA-2048 非对称加密
  - `Sm2AlgorithmStrategy` - SM2 国密非对称加密
  - `SignAlgorithmStrategy` - SHA256withRSA 签名验签
  - `Md5AlgorithmStrategy` - MD5 摘要
  - `Sm3AlgorithmStrategy` - SM3 国密摘要
  - `CryptoService` - 加密服务门面（策略模式调度）

### 业务服务（pcm-kms-server）

  - `ClientAppService` - 应用管理（创建、启用生成凭证和默认密钥、列表查询）
  - `KeyService` - 密钥管理（创建、列表、启用/禁用、轮转、公钥获取）
  - `CryptoBizService` - 加解密业务（加密、解密、签名、验签、摘要）
  - `AuditLogService` - 审计日志

### API 接口

  - `POST /api/admin/apps` - 创建应用
  - `GET /api/admin/apps` - 应用列表
  - `GET /api/admin/apps/{id}` - 应用详情
  - `POST /api/admin/apps/{id}/enable` - 启用应用
  - `POST /api/admin/keys` - 创建密钥
  - `GET /api/admin/keys` - 密钥列表
  - `GET /api/admin/keys/{id}` - 密钥详情
  - `POST /api/admin/keys/{id}/enable` - 启用密钥
  - `POST /api/admin/keys/{id}/disable` - 禁用密钥
  - `POST /api/admin/keys/{id}/rotate` - 密钥轮转
  - `POST /api/crypto/encrypt` - 加密
  - `POST /api/crypto/decrypt` - 解密
  - `POST /api/crypto/sign` - 签名
  - `POST /api/crypto/verify` - 验签
  - `POST /api/crypto/digest` - 摘要
  - `GET /api/crypto/public-key/{alias}` - 获取公钥
  - `GET /api/system/ping` - 探活
