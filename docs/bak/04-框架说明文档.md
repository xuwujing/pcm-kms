## 1. 项目简介

PCM-KMS 是一个轻量级密钥管理系统（Key Management System），提供密钥全生命周期管理和统一的加解密服务。项目设计理念：

- **纯净**：零公司内部框架依赖，标准 Maven 项目
- **轻量**：`java -jar` 即可启动，SQLite 模式下零外部依赖
- **渐进**：核心功能最小化，高级特性按需开启
- **兼容**：同时支持 MySQL/SQLite、Redis/Caffeine

## 5. 快速启动

### 5.1 环境要求

| 软件 | 最低版本 | 推荐版本 |
|------|----------|----------|
| JDK | 11 | 17 |
| Maven | 3.6 | 3.9 |
| Node.js | 16 | 18+ |
| MySQL | 5.7 | 8.0+（可选） |
| Redis | 5.0 | 7.0+（可选） |

### 5.2 后端启动

```bash
# 1. 克隆项目
git clone https://github.com/your-org/pcm-kms.git
cd pcm-kms

# 2. 编译
mvn clean package -DskipTests

# 3. 启动（SQLite 模式，零依赖）
java -jar pcm-kms-server/target/pcm-kms-server.jar

# 4. 验证
curl http://localhost:8080/actuator/health
# 返回: {"status":"UP"}
```

### 5.3 使用 MySQL

```bash
# 1. 创建数据库
mysql -u root -p -e "CREATE DATABASE pcm_kms DEFAULT CHARACTER SET utf8mb4;"

# 2. 启动时指定 profile
java -jar pcm-kms-server/target/pcm-kms-server.jar --spring.profiles.active=mysql

# 或在 application.yml 中配置:
# spring:
#   profiles:
#     active: mysql
```

### 5.4 使用 Redis

```bash
# 启动时指定 profile
java -jar pcm-kms-server/target/pcm-kms-server.jar --spring.profiles.active=redis

# 或组合使用
java -jar pcm-kms-server/target/pcm-kms-server.jar --spring.profiles.active=mysql,redis
```

### 5.5 前端启动

```bash
cd pcm-kms-admin-ui

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 访问 http://localhost:5173
```

### 5.6 Docker 一键启动

```bash
cd docker
docker-compose up -d
```

## 7. 核心设计

### 7.1 加密引擎 — 策略模式

```
                    ┌─────────────────────┐
                    │   CryptoEngine      │
                    │  (策略选择器)         │
                    └──────────┬──────────┘
                               │
              ┌────────────────┼────────────────┐
              │                │                │
     ┌────────┴────────┐ ┌───┴────────┐ ┌─────┴──────────┐
     │ AlgorithmStrategy│ │AlgorithmStrategy│ │AlgorithmStrategy│
     │ (接口)           │ │(接口)          │ │(接口)          │
     └────────┬────────┘ └───┬────────┘ └─────┬──────────┘
              │              │                │
    ┌─────────┼─────────┐    │    ┌──────────┼──────────┐
    │         │         │    │    │          │          │
┌───┴──┐ ┌───┴──┐ ┌───┴──┐ │ ┌──┴──┐ ┌────┴───┐ ┌───┴────┐
│ AES  │ │ SM4  │ │ RSA  │ │ │ SM2 │ │ SIGN   │ │ HASH   │
│Strat.│ │Strat.│ │Strat.│ │ │Strat│ │Strat.  │ │Strat.  │
└──────┘ └──────┘ └──────┘ │ └─────┘ └────────┘ └────────┘
                            │
         对称加密             │  非对称加密      签名/摘要
```

**关键代码：**

```java
// 策略接口
public interface AlgorithmStrategy {
    String encrypt(String plainText, String key);
    String decrypt(String cipherText, String key);
    KeyPairDTO generateKeyPair();
}

// 策略选择器
@Component
public class CryptoEngine {
    private final Map<String, AlgorithmStrategy> strategyMap;

    // Spring 自动注入所有 AlgorithmStrategy 实现
    // Bean 名称 = 算法code + "AlgorithmStrategy"
    // 例如: aesAlgorithmStrategy, sm4AlgorithmStrategy
    public CryptoEngine(Map<String, AlgorithmStrategy> strategyMap) {
        this.strategyMap = strategyMap;
    }

    public AlgorithmStrategy getStrategy(AlgorithmEnum algorithm) {
        String beanName = algorithm.getCode() + "AlgorithmStrategy";
        return strategyMap.get(beanName);
    }
}
```

### 7.2 缓存策略 — 自动降级

```
                    ┌──────────────────┐
                    │   CacheManager   │
                    │   (缓存抽象层)     │
                    └────────┬─────────┘
                             │
              ┌──────────────┴──────────────┐
              │                             │
    ┌─────────┴─────────┐        ┌─────────┴─────────┐
    │  Redis 可用？      │        │  Caffeine (本地)   │
    │  YES ──→ Redis    │        │  (降级方案)         │
    │  NO  ──→ Caffeine │        │                    │
    └───────────────────┘        └───────────────────┘
```

```java
@Configuration
public class CacheConfig {

    @Bean
    @ConditionalOnProperty(name = "kms.cache.type", havingValue = "redis", matchIfMissing = false)
    public CacheManager redisCacheManager(RedisConnectionFactory factory) {
        // Redis 缓存管理器
    }

    @Bean
    @ConditionalOnMissingBean(CacheManager.class)
    public CacheManager caffeineCacheManager() {
        // Caffeine 本地缓存（默认）
        CaffeineCacheManager manager = new CaffeineCacheManager();
        manager.setCaffeine(Caffeine.newBuilder()
            .maximumSize(10000)
            .expireAfterWrite(10, TimeUnit.MINUTES));
        return manager;
    }
}
```

### 7.4 签名验证流程

```
Client                              KMS Server
  │                                     │
  │  1. 构造请求体 body                  │
  │  2. timestamp = now()               │
  │  3. nonce = random()                │
  │  4. sign = HMAC-SHA256(             │
  │       secret, body+timestamp+nonce) │
  │                                     │
  │  ──── POST + Headers ───────────→   │
  │                                     │
  │                          5. 验证 timestamp 有效期
  │                          6. 验证 nonce 未使用
  │                          7. 重新计算 sign 比对
  │                          8. 记录 nonce（防重放）
  │                                     │
  │  ←──── Response ────────────────    │
```

## 8. 开发指南

### 8.1 添加新算法

1. 在 `AlgorithmEnum` 中添加枚举值
2. 创建 `XxxAlgorithmStrategy` 实现 `AlgorithmStrategy` 接口
3. Bean 命名规则：`{code}AlgorithmStrategy`（如 `sm4AlgorithmStrategy`）
4. 无需修改其他代码，Spring 自动注入

```java
@Component("sm4AlgorithmStrategy")
public class Sm4AlgorithmStrategy implements AlgorithmStrategy {
    // 实现 encrypt / decrypt / generateKeyPair
}
```

### 8.2 添加新接口

1. 在 `pcm-kms-server/controller/` 创建 Controller
2. 在 `pcm-kms-server/service/` 创建 Service 接口和实现
3. 在 `pcm-kms-server/mapper/` 创建 Mapper（如需新表）
4. Swagger 文档自动生成

### 8.3 代码风格

- 使用 Lombok 简化 POJO（`@Data`, `@Builder`, `@AllArgsConstructor`）
- Controller → Service → Mapper 三层，不跨层调用
- DTO 用于接口传输，Entity 用于数据库映射，VO 用于视图展示
- 使用 MapStruct 做对象转换，避免手写 get/set

### 8.4 单元测试

```java
@SpringBootTest
class AesStrategyTest {

    @Autowired
    private AlgorithmStrategy aesStrategy;

    @Test
    void testEncryptDecrypt() {
        String plainText = "Hello KMS";
        KeyPairDTO keyPair = aesStrategy.generateKeyPair();

        String cipherText = aesStrategy.encrypt(plainText, keyPair.getSecretKey());
        String decrypted = aesStrategy.decrypt(cipherText, keyPair.getSecretKey());

        assertEquals(plainText, decrypted);
    }
}
```

## 9. 构建与部署

### 9.1 构建命令

```bash
# 完整构建
mvn clean package

# 跳过测试
mvn clean package -DskipTests

# 构建 Docker 镜像
docker build -t pcm-kms:latest .

# 前端构建
cd pcm-kms-admin-ui && npm run build
```

### 9.2 Docker 部署

```yaml
# docker-compose.yml
version: '3.8'
services:
  kms-server:
    image: pcm-kms:latest
    ports:
      - "8080:8080"
    environment:
      - SPRING_PROFILES_ACTIVE=mysql,redis
      - KMS_MASTER_KEY=your-master-key-hex
      - MYSQL_PASSWORD=your-password
      - REDIS_HOST=redis
    depends_on:
      - mysql
      - redis

  mysql:
    image: mysql:8.0
    environment:
      MYSQL_ROOT_PASSWORD: your-password
      MYSQL_DATABASE: pcm_kms
    volumes:
      - mysql_data:/var/lib/mysql

  redis:
    image: redis:7-alpine
    volumes:
      - redis_data:/data

volumes:
  mysql_data:
  redis_data:
```

### 9.3 环境变量清单

| 变量 | 必填 | 默认值 | 说明 |
|------|------|--------|------|
| `KMS_MASTER_KEY` | 生产必填 | 自动生成 | 主密钥（256位 Hex） |
| `MYSQL_PASSWORD` | MySQL 模式必填 | root | 数据库密码 |
| `REDIS_HOST` | Redis 模式必填 | localhost | Redis 地址 |
| `REDIS_PASSWORD` | 否 | — | Redis 密码 |
| `KMS_CLIENT_ID` | SDK 必填 | — | 应用 ID |
| `KMS_CLIENT_SECRET` | SDK 必填 | — | 应用密钥 |
