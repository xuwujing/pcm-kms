# PCM-KMS 开发进度周期

> 版本：v1.0 | 日期：2026-06-10

---

## 总体说明

本项目是一个完整的密钥管理系统，涉及后端 7 个模块 + 前端管理后台 + SDK。按功能优先级和依赖关系分为 5 个阶段，预计总工期约 **12 周**（单人开发，业余时间）。

每个阶段结束时产出可运行的版本，可以逐步交付使用。

---

## 阶段一：项目骨架 + 基础框架（第 1-2 周）

**目标**：项目能跑起来，数据库能连上，Swagger 能访问。

### 后端

| 任务 | 说明 | 预估 |
|------|------|------|
| 父 POM 搭建 | 统一依赖版本管理（Spring Boot 2.7、Spring Cloud 2021、MyBatis-Plus 3.5） | 0.5d |
| pcm-kms-common | 公共模块：统一响应体、异常定义、基础工具类 | 1d |
| pcm-kms-api | DTO/VO 定义、Feign 接口声明 | 0.5d |
| pcm-kms-core | MyBatis-Plus 配置、多数据源（MySQL + SQLite）自动切换 | 1d |
| pcm-kms-server | Spring Boot 启动类、Knife4j 集成、全局异常处理、CORS | 1d |
| 数据库初始化 | MySQL 建表脚本 + SQLite 建表脚本 | 0.5d |
| 缓存策略 | Redis 配置 + Caffeine 自动降级（检测 Redis 是否可用） | 1d |
| Nacos 集成 | 服务注册 + 配置中心（可配置关闭，单机模式不依赖） | 0.5d |

### 前端

## 风险与应对

| 风险 | 影响 | 应对 |
|------|------|------|
| 业余时间不稳定 | 进度延迟 | 按阶段交付，每个阶段独立可用 |
| 国密算法兼容性 | SM2/SM4 在某些 JDK 下需额外配置 | 提前验证，提供 JCE 配置说明 |
| SQLite 并发限制 | 多实例写入冲突 | 文档注明 SQLite 仅适合单机/开发 |
| 前端开发效率 | 个人不擅长前端 | 使用 Element Plus 模板，减少自定义样式 |
