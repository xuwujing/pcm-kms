## 1. 项目简介

PCM-KMS 是一个轻量级密钥管理系统（Key Management System），提供密钥全生命周期管理和统一的加解密服务。

**设计理念**：
- **纯净**：零公司内部框架依赖，标准 Maven 项目
- **轻量**：`java -jar` 即可启动，SQLite 模式下零外部依赖
- **渐进**：核心功能最小化，高级特性按需开启
- **兼容**：同时支持 MySQL/SQLite、Redis/Caffeine

**版本历史**：
- V1.x（base-kms）：基于 Dubbo + Fastjson + 公司内部框架，已稳定运行
- V2.0（pcm-kms）：全面重写，HTTP REST + Jackson + 零内部依赖

### 5.2 后端启动

```bash
# 1. 克隆项目
git clone https://github.com/your-org/pcm-kms.git
cd pcm-kms

# 2. 编译
mvn clean package -DskipTests

# 3. 启动（SQLite 模式，零依赖）
java -jar pcm-kms-server/target/pcm-kms-server.jar

# 4. 验证
curl http://localhost:8080/actuator/health
# 返回: {"status":"UP"}
```

启动后访问：
- 管理后台：`http://localhost:8080`
- Swagger 文档：`http://localhost:8080/doc.html`
- 默认账号：`admin` / `admin123`

### 5.3 使用 MySQL

```bash
# 创建数据库
mysql -u root -p -e "CREATE DATABASE pcm_kms DEFAULT CHARACTER SET utf8mb4;"

# 启动时指定 profile
java -jar pcm-kms-server/target/pcm-kms-server.jar --spring.profiles.active=mysql
```

### 5.4 使用 Redis

```bash
java -jar pcm-kms-server/target/pcm-kms-server.jar --spring.profiles.active=redis

# 组合使用
java -jar pcm-kms-server/target/pcm-kms-server.jar --spring.profiles.active=mysql,redis
```

### 5.5 前端启动

```bash
cd pcm-kms-admin-ui
npm install
npm run dev
# 访问 http://localhost:5173
```

### 5.6 Docker 一键启动

```bash
cd docker
docker-compose up -d
```

## 7. 核心设计

### 7.1 加密引擎 — 策略模式

```
                    ┌─────────────────────┐
                    │   CryptoEngine      │
                    │  (策略选择器)         │
                    │  selectorImpl()     │
                    └──────────┬──────────┘
                               │
              ┌────────────────┼────────────────┐
              │                │                │
     ┌────────┴────────┐ ┌───┴────────┐ ┌─────┴──────────┐
     │ AlgorithmStrategy│ │AlgorithmStrategy│ │AlgorithmStrategy│
     │ (接口)           │ │(接口)          │ │(接口)          │
     └────────┬────────┘ └───┬────────┘ └─────┬──────────┘
              │              │                │
    ┌─────────┼─────────┐    │    ┌──────────┼──────────┐
    │         │         │    │    │          │          │
┌───┴──┐ ┌───┴──┐ ┌───┴──┐ │ ┌──┴──┐ ┌────┴───┐ ┌───┴────┐
│ AES  │ │ SM4  │ │ RSA  │ │ │ SM2 │ │ SIGN   │ │ HASH   │
│Strat.│ │Strat.│ │Strat.│ │ │Strat│ │Strat.  │ │Strat.  │
└──────┘ └──────┘ └──────┘ │ └─────┘ └────────┘ └────────┘
         对称加密           │  非对称加密      签名/摘要
```

**关键代码（与旧版逻辑一致）：**

```java
// 策略接口
public interface AlgorithmStrategy {
    String encrypt(String plainText, String publicKey);
    String encryptById(String plainText, String secretId);
    String decrypt(String cipherText, String privateKey);
    String decryptById(String cipherText, String secretId);
    KeyPairDTO generateKeyPair();
}

// 策略选择器（Spring 自动注入所有 AlgorithmStrategy 实现）
@Service
public class CryptoService {
    @Autowired
    private Map<String, AlgorithmStrategy> algorithmStrategyMap;

    public AlgorithmStrategy selectorImpl(AlgorithmEnum algorithm) {
        String code = algorithm.getCode();
        String beanName = code + "AlgorithmStrategy";
        return algorithmStrategyMap.get(beanName);
    }
}
```

### 7.2 AES 加密实现（CBC + 随机 IV）

与旧版实现一致，关键点：
- 使用 AES-128-CBC + PKCS5Padding
- 每次加密生成随机 IV（16 字节）
- IV 与密文合并存储（前 16 字节为 IV）
- 密钥材料使用 MasterKey 二次加密存储

### 7.3 Interceptor 链（替代旧版 Dubbo Filter 链）

```
旧版 Dubbo Filter 链：
  ValidationSignFilter → RateLimitFilter → GetClientInfoFilter
  → KmsDubboExceptionFilter → LogFilter

新版 HTTP Interceptor 链：
  SignAuthInterceptor → RateLimitInterceptor → ClientInfoInterceptor
  → ExceptionInterceptor → LogInterceptor
```

### 7.4 缓存策略 — 自动降级

```java
@Configuration
public class CacheConfig {

    @Bean
    @ConditionalOnProperty(name = "spring.cache.type",
                           havingValue = "redis")
    public CacheManager redisCacheManager(
            RedisConnectionFactory factory) {
        // Redis 缓存管理器
    }

    @Bean
    @ConditionalOnMissingBean(CacheManager.class)
    public CacheManager caffeineCacheManager() {
        // Caffeine 本地缓存（默认）
        CaffeineCacheManager manager = new CaffeineCacheManager();
        manager.setCaffeine(Caffeine.newBuilder()
            .maximumSize(10000)
            .expireAfterWrite(10, TimeUnit.MINUTES));
        return manager;
    }
}
```

```
  │                                     │
  │  1. 构造请求体 body                  │
  │  2. timestamp = now()               │
  │  3. nonce = random()                │
  │  4. sign = HMAC-SHA256(             │
  │       secret, body+timestamp+nonce) │
  │                                     │
  │  ──── POST + Headers ───────────→   │
  │                                     │
  │                          5. 验证 timestamp 有效期
  │                          6. 验证 nonce 未使用
  │                          7. 重新计算 sign 比对
  │                          8. 记录 nonce（防重放）
  │                                     │
  │  ←──── Response ────────────────    │
```

### 7.7 限流机制

参考高德地图 API 设计，分为每日限额和分钟限额：

```
每日限额：
  Redis Key: kms:ratelimit:daily:{clientId}:{yyyyMMdd}
  过期时间: 次日 00:00
  默认值: 1,000,000

分钟限额：
  Redis Key: kms:ratelimit:minute:{clientId}:{yyyyMMddHHmm}
  过期时间: 下一分钟
  默认值: 1,000

无 Redis 时降级为 Caffeine 本地计数（单机有效）
```

## 8. 开发指南

### 8.1 添加新算法

1. 在 `AlgorithmEnum` 中添加枚举值
2. 创建 `XxxAlgorithmStrategy` 实现 `AlgorithmStrategy` 接口
3. Bean 命名规则：`{code}AlgorithmStrategy`（如 `sm4AlgorithmStrategy`）
4. 无需修改其他代码，Spring 自动注入

```java
@Component("sm4AlgorithmStrategy")
public class Sm4AlgorithmStrategy implements AlgorithmStrategy {
    // 实现 encrypt / decrypt / generateKeyPair
}
```

### 8.2 添加新接口

1. 在 `pcm-kms-server/controller/` 创建 Controller
2. 在 `pcm-kms-server/service/` 创建 Service 接口和实现
3. 在 `pcm-kms-server/mapper/` 创建 Mapper（如需新表）
4. Swagger 文档自动生成

### 8.3 代码风格

- 使用 Lombok 简化 POJO（`@Data`, `@Builder`）
- Controller → Service → Mapper 三层，不跨层调用
- DTO 用于接口传输，Entity 用于数据库映射，VO 用于视图展示
- 使用 MapStruct 做对象转换

### 8.4 单元测试

```java
@SpringBootTest
class AesAlgorithmStrategyTest {

    @Autowired
    private AlgorithmStrategy aesStrategy;

    @Test
    void testEncryptDecrypt() {
        String plainText = "Hello KMS";
        KeyPairDTO keyPair = aesStrategy.generateKeyPair();

        String cipherText = aesStrategy.encrypt(
            plainText, keyPair.getSecretKey());
        String decrypted = aesStrategy.decrypt(
            cipherText, keyPair.getSecretKey());

        assertEquals(plainText, decrypted);
    }
}
```

## 10. 从旧版迁移

### 10.1 迁移对照

| 项目 | 旧版（base-kms） | 新版（pcm-kms） |
|------|-----------------|-----------------|
| GroupId | com.baj.kms | com.pcm |
| Java | 8 | 17 |
| Parent POM | bajcommon-parent | 无（标准 Spring Boot） |
| RPC | Dubbo | HTTP REST |
| JSON | Fastjson | Jackson |
| 数据库 | MySQL | MySQL + SQLite |
| 缓存 | Redis | Redis + Caffeine |
| 配置中心 | Luffy | 本地配置 + 环境变量 |
| 前端 | Swagger UI | Vue 3 管理后台 |

### 10.2 业务方迁移步骤

1. 在新版 KMS 中创建对应的应用和密钥
2. 替换 Maven 依赖：
   ```xml
   <!-- 旧 -->
   <dependency>
       <groupId>com.baj.kms</groupId>
       <artifactId>kms-encrypt-starter</artifactId>
   </dependency>
   <!-- 新 -->
   <dependency>
       <groupId>com.pcm</groupId>
       <artifactId>pcm-kms-client-starter</artifactId>
   </dependency>
   ```
3. 修改配置：
   ```yaml
   # 旧
   kms.consumer.private.key=MIICdwIBADANBgkqhkiG9w0B...
   # 新
   kms.client.client-secret=your_secret_here
   ```
4. 注解保持不变（`@KmsEncryptField`、`@KmsDecryptField`、`@KmsMethod`、`@KmsParam`）
5. 编程式调用替换：
   ```java
   // 旧
   @Reference
   private SecretKeyRpcService secretKeyRpcService;
   // 新
   @Autowired
   private KmsClient kmsClient;
   ```
6. 逐应用灰度切换，验证加解密结果一致
