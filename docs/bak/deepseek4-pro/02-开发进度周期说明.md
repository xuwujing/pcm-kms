# PCM-KMS 开发进度周期说明

> 版本：V2.0 | 作者：潘成明 | 日期：2026-06-10

---

## 概述

PCM-KMS V2.0 是在旧版 base-kms（V1.4）基础上的全面重写。旧版已完成核心功能并稳定运行，V2.0 的核心工作是**技术栈升级**和**架构重构**，而非从零开发。

旧版已有功能（可直接复用逻辑）：
- 租户入驻、应用管理、密钥 CRUD
- 加密引擎策略模式（AES/SM4/RSA/SM2/SIGN/MD5）
- 自动加签/验签 Filter 链
- 审计日志 AOP
- 密钥版本管理 + 轮转
- 密钥授权机制
- 账户独立权限
- 应用访问限制（Redis Lua 令牌桶）
- Starter 注解式加解密（@KmsEncryptField/@KmsDecryptField/@KmsMethod/@KmsParam）

V2.0 新增工作：
- 去公司内部框架依赖
- Dubbo → HTTP REST
- Fastjson → Jackson
- 新增 SQLite 支持
- 新增 Caffeine 本地缓存降级
- 新增 Vue 3 管理后台

## 开发规范

### 分支策略

```
main          # 稳定发布分支
├── develop   # 开发主分支
│   ├── feature/phase1-xxx
│   ├── feature/phase2-xxx
│   └── ...
└── release/v2.0.0
```

### 提交规范

```
feat: 新增密钥版本管理功能
fix: 修复 AES 解密 IV 长度异常
docs: 更新快速接入文档
refactor: 重构加密引擎策略选择器
test: 补充 RSA 加解密单元测试
chore: 升级 Spring Boot 版本
```

### 代码规范

- 后端遵循阿里巴巴 Java 开发手册
- 前端遵循 Vue 3 风格指南
- 所有公共 API 必须有 Swagger 注解
- 核心逻辑必须有单元测试

## 旧版代码复用清单

以下旧版代码逻辑可直接复用，无需重新设计：

| 模块 | 文件 | 复用方式 |
|------|------|----------|
| 加密引擎 | `AlgorithmStrategy.java` + 6 种实现 | 直接迁移，接口不变 |
| 加密服务 | `CryptoService.java`（策略选择器） | 直接迁移 |
| 密钥管理 | `KeyBaseManager/Service` | 迁移，DAO 层改为 MyBatis-Plus |
| 密钥元数据 | `KeyExtensionsManager/Service` | 迁移 |
| 应用管理 | `ClientInfoManager/Service` | 迁移 |
| 审计日志 | `LogOperationManager/Service` + AOP | 迁移 |
| 权限管理 | `PermissionManager/Service` | 迁移 |
| 用户管理 | `UserInfoManager/Service` + Sa-Token | 迁移 |
| 限流 | `RateLimitConfigManager/Service` + Handler | 迁移，新增 Caffeine 降级 |
| 密钥授权 | `ClientAuthorizationManager/Service` | 迁移 |
| Starter 注解 | `@KmsEncryptField/@KmsDecryptField/@KmsMethod/@KmsParam` | 迁移，底层从 Dubbo 改为 HTTP |
| 加解密工具 | `AesUtils/CryptoConvertUtil/PasswordUtils` | 直接迁移 |

以下需要重写：

| 模块 | 原因 |
|------|------|
| Dubbo Service 实现 | 改为 REST Controller |
| Dubbo Filter 链 | 改为 HTTP Interceptor 链 |
| 自动加签 Filter | 改为 HTTP 签名拦截器 |
| Fastjson 序列化 | 改为 Jackson |
| bajcommon 依赖 | 替换为标准库 |
| 配置中心集成 | 改为本地配置 + 环境变量 |
