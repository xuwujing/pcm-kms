# PCM-KMS 协作记录模板

建议每次交接都追加一段记录，方便其他智能体或开发者继续工作。

---

## 记录模板

```md
### YYYY-MM-DD HH:mm

- 负责人：
- 当前阶段：
- 本次目标：
- 已完成：
- 改动文件：
- 影响模块：
- 未完成：
- 风险与注意事项：
- 下一位建议优先处理：
```

---

## 示例

### 2026-06-10 16:20

- 负责人：Codex
- 当前阶段：设计与文档阶段
- 本次目标：统一 KMS 设计文档、整理 README、补充多智能体协作说明
- 已完成：
  - 重写 README 为开源仓库风格
  - 重写 4 份主文档

  - 新增协作记录模板

  - README 中的启动命令仍属于规划态
- 风险与注意事项：

```
